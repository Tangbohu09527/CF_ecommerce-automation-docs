## 规划能力说明

- 图片、Office、PDF、ZIP、中文文件名和连续多附件仍需 `agent-wechat` 技术验证。
- 文件内容解析、视觉模型和知识库属于后续规划，不代表当前已经具备。
- 第一阶段不建设独立 OCR；是否补充 OCR 能力需按实际业务需求重新评估。
- FileBrowser Enterprise 与自动化主线并行推进，正式文件自动化访问仍必须经过 File Service、权限检查和审计。

## 当前阶段结论

项目仍处于阶段 1。微信入口层的部署和基础读写验证已经完成，下一步工作集中在 Gateway 设计、Hermes 接入和端到端主链路建设；在这些环节完成并通过验收前，不对外宣称企业业务自动化已经可用。
